# Proto.io

## Descrição

Proto.io é um projeto de site web responsivo que apresenta uma interface moderna para exibir produtos, notícias, equipe e outras seções relacionadas a tecnologia e gaming. O site inclui elementos interativos como carrosséis, animações de mouse e um layout otimizado para diferentes dispositivos.

## Tecnologias Utilizadas

- **HTML5**: Estrutura do site
- **CSS3**: Estilização e layout responsivo
- **JavaScript**: Funcionalidades interativas

## Como Executar

1. Clone ou baixe o repositório para o seu computador.
2. Abra o arquivo `index.html` em qualquer navegador web moderno (Chrome, Firefox, Edge, etc.).
3. O site será carregado e você poderá navegar pelas diferentes seções.

## Estrutura do Projeto

```
Proto.io/
├── index.html          # Página principal do site
├── main.js             # Scripts JavaScript para funcionalidades
├── img/                # Imagens do projeto
│   └── Proto.io - UI/  # Pasta com imagens da interface
└── styles/             # Arquivos de estilo CSS
    ├── about.css       # Estilos da seção "Sobre"
    ├── carousel.css    # Estilos do carrossel
    ├── footer.css      # Estilos do rodapé
    ├── gear.css        # Estilos relacionados a equipamentos
    ├── global.css      # Estilos globais
    ├── header.css      # Estilos do cabeçalho
    ├── index.css       # Estilos da página inicial
    ├── mouse.css       # Estilos para animações de mouse
    ├── news.css        # Estilos da seção de notícias
    ├── products.css    # Estilos da seção de produtos
    ├── razer.css       # Estilos específicos para Razer
    ├── store-container.css  # Estilos do container da loja
    └── team.css        # Estilos da seção de equipe
```

## Funcionalidades

- **Header Navegável**: Menu de navegação para diferentes seções.
- **Carrossel**: Exibição dinâmica de conteúdo.
- **Seções de Produtos**: Apresentação de produtos com imagens e descrições.
- **Notícias**: Área para atualizações e anúncios.
- **Equipe**: Informações sobre a equipe.
- **Rodapé**: Links e informações de contato.
